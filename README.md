# Python Console Roulette Game

A simple, fun, and colorful roulette game built with Python. This project was created to demonstrate basic Python skills, including user input handling, loops, conditional logic, and using external libraries like `colorama`.

## Features
- European roulette wheel (numbers 0-36)
- Bet on specific numbers, colors, odd/even, or low/high
- Fun, colorful interface powered by `colorama`
- Built-in validation for user input

## How to Run
1. Clone the repository.
2. Install the required library: `pip install colorama`
3. Run the script: `python roulette.py`
